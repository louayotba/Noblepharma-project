# Noble Pharma – Role Selection

نسخة HTML نظيفة ومتجاوبة لشاشة اختيار الدور في تطبيق Noble Pharma.

## المميزات
- ملف واحد فقط (index.html) + favicon
- يدعم العربية والإنجليزية (زر التبديل)
- تصميم قريب جداً من النسخة الأصلية
- يعمل مباشرة على GitHub Pages بدون أي إعدادات إضافية

## طريقة الرفع على GitHub Pages
1. أنشئ مستودع جديد
2. ارفع الملفين: `index.html` و `favicon.png`
3. Settings → Pages → Source: Deploy from a branch → main / root
4. انتظر دقيقة وسيظهر الموقع

## الملفات
- `index.html` — الصفحة الرئيسية
- `favicon.png` — أيقونة الموقع
